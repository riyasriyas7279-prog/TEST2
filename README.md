
# ✈️ TravelPass – Android Application

## 📌 Project Overview
TravelPass is an Android application designed to manage traveller information and personal travel preferences. It provides a simple and user-friendly interface for signing in, viewing traveller details, and updating profile settings.

## 🚀 Features

- **User Login:** Login screen with username and password fields.
- **Remember Me:** Option to remember login details.
- **Traveller Dashboard:** Displays traveller information.
- **Profile Management:** View and edit personal details.
- **Distance Preference:** Select Kilometres (KM) or Miles (MI).
- **Temperature Preference:** Choose Celsius or Fahrenheit.
- **Travel Alerts:** Enable or disable travel notifications.
- **Save Profile:** Save updated profile preferences.

## 🛠️ Technologies Used

- Android Studio
- Java / Android SDK
- XML for UI Design
- Gradle Build System
- AndroidX Libraries
- Material Components

## ⚙️ Installation and Execution

1. Install Android Studio.
2. Clone this repository:

   ```bash
   git clone https://github.com/riyasriyas7279-prog/TEST2.git
   ```

3. Open Android Studio.
4. Select **File → Open**.
5. Choose the downloaded TEST2 folder.
6. Wait for Gradle Sync to complete.
7. Start an Android emulator or connect an Android device.
8. Click the **Run ▶** button.

## 🔄 Application Workflow

1. Launch the application.
2. Enter login details.
3. Open the Traveller Dashboard.
4. View traveller information.
5. Select Edit Profile.
6. Update personal details and preferences.
7. Save the profile.
